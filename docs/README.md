## 📱 App Overview

MoneyManager is a comprehensive finance tracking application that allows users to:
- Track income and expenses across multiple accounts
- Use default or custom categories for transactions
- Backup and sync data across devices (optional)
- Start quickly with anonymous accounts or full authentication

The app prioritizes user choice and flexibility, allowing users to begin tracking immediately while providing optional backup and sync capabilities.
