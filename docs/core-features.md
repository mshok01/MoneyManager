# Core Features Documentation

## 🎯 Feature Overview

MoneyManager is designed around four core pillars that provide comprehensive financial tracking while maintaining simplicity and user control.

## 💰 1. Income & Expense Tracking

### Primary Functionality
- **Transaction Recording**: Quick entry of income and expense transactions
- **Real-time Balance**: Automatic calculation of account balances
- **Transaction History**: Chronological list of all financial activities
- **Search & Filter**: Find specific transactions by date, amount, or category

### Transaction Types
```
Income Types:
├── Salary
├── Freelance
├── Investment Returns
├── Gifts Received
└── Other Income

Expense Types:
├── Food & Dining
├── Transportation
├── Utilities
├── Entertainment
├── Healthcare
└── Other Expenses
```

### User Experience
- **Quick Add**: Floating action button for immediate transaction entry
- **Smart Defaults**: Remember frequently used categories and amounts
- **Bulk Operations**: Select and modify multiple transactions
- **Recurring Transactions**: Set up automatic recurring entries

## 🏦 2. Multiple Account Management

### Account Types
Based on user memory: "home/office/apartment" accounts supported

```
Account Categories:
├── Personal
│   ├── Home
│   ├── Personal Savings
│   └── Emergency Fund
├── Professional  
│   ├── Office
│   ├── Business Checking
│   └── Business Savings
└── Property
    ├── Apartment
    ├── Rental Property
    └── Investment Property
```

### Account Features
- **Independent Balances**: Each account maintains separate balance
- **Account Switching**: Quick toggle between accounts
- **Transfer Between Accounts**: Move money between user accounts
- **Account Analytics**: Individual account performance tracking

### Visual Organization
- **Account Cards**: Visual representation of each account
- **Color Coding**: Unique colors for easy account identification
- **Balance Overview**: Summary view of all account balances
- **Account Icons**: Customizable icons for each account type

## 📊 3. Category System

### Default Categories
Pre-configured categories for immediate use:

#### Income Categories
- **Employment**: Salary, wages, bonuses
- **Business**: Freelance, consulting, business income
- **Investments**: Dividends, interest, capital gains
- **Other**: Gifts, refunds, miscellaneous income

#### Expense Categories
- **Essential**: Housing, utilities, groceries, transportation
- **Lifestyle**: Dining, entertainment, shopping, hobbies
- **Financial**: Insurance, taxes, debt payments, savings
- **Health**: Medical, dental, pharmacy, fitness

### Custom Categories
- **User-Defined**: Create unlimited custom categories
- **Subcategories**: Organize with parent-child relationships
- **Category Icons**: Choose from icon library or upload custom
- **Color Themes**: Assign colors for visual organization

### Category Management
- **Edit/Delete**: Modify existing categories
- **Merge Categories**: Combine similar categories
- **Category Analytics**: Spending patterns by category
- **Budget Allocation**: Set spending limits per category

## 🔄 4. Data Backup & Sync

### Anonymous Account Features
- **Local Storage**: All data stored locally on device
- **Firebase Anonymous**: Secure local account creation
- **No Personal Info**: No email or personal data required
- **Instant Access**: Immediate app functionality

### Backup Account Integration
- **Google Sign-in**: Backup to Google Drive
- **Apple Sign-in**: Backup to iCloud
- **Cross-Device Sync**: Access data on multiple devices
- **Automatic Backup**: Regular data synchronization

### Data Management
- **Account Linking**: Upgrade anonymous to full account
- **Data Migration**: Seamless transfer of local data to cloud
- **Conflict Resolution**: Smart merging of local and cloud data
- **Export Options**: Download data in various formats
